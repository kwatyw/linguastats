Я изучаю несколько языков одновременно (английский, французский, китайский). В какой-то момент мне надоело переключаться между Anki и Duolingo, чтобы понимать, сколько я занимаюсь. Мне хотелось иметь одну страничку, где было бы видно мой прогресс по всем языкам сразу. Так появился этот проект!

LinguaStats умеет загружать экспорты из Anki (csv с историей ревью) и Duolingo (json с дневной активностью), приводить их к одному формату и считать различные показатели: retention, средние xp в неделю, длину стриков, сравнение языков между собой. Сверху Streamlit-дашборд с вкладками и сайдбаром, где можно выбрать язык и период. Запуск: `streamlit run app.py`. Данные в `data/` синтетические.
