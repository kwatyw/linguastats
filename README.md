# LinguaStats

Я учу несколько языков одновременно (французский, немецкий, японский и немного испанский) и в какой-то момент задолбался переключаться между Anki и Duolingo, чтобы понять, сколько я реально занимаюсь. Хотелось одну страничку, где было бы видно мой прогресс по всем языкам сразу — где я молодец, а где забил уже на две недели. Так появился этот проект.

LinguaStats умеет загружать экспорты из Anki (csv с историей ревью) и Duolingo (json с дневной активностью), приводить их к одному формату и считать всякие штуки — retention, средние xp в неделю, длину стриков, сравнение языков между собой. Сверху Streamlit-дашборд с вкладками и сайдбаром, где можно выбрать язык и период. Запуск: `streamlit run app.py`. Данные в `data/` синтетические, замените на свои экспорты если хочется на реальных цифрах посмотреть.
